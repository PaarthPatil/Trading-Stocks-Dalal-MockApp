# 🎨 FRONTEND UI PROMPT

Build a React + Tailwind frontend for a stock trading simulation.

## PAGES:

### 1. Dashboard

* List of stocks
* Prices
* Buy/Sell buttons

### 2. Company Page

* Price history graph
* Users holding stock

### 3. Teams Page

* List all teams
* Show team portfolios

### 4. Portfolio Page

* User holdings
* Profit/Loss

## REQUIREMENTS:

* Use clean modern UI (like trading platforms)
* Mobile responsive
* Use charts (Recharts or Chart.js)

## RULES:

* No business logic in frontend
* Only API calls

## OUTPUT:

* Full React code
* Components structured cleanly
