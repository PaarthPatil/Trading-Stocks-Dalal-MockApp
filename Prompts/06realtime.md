# ⚡ REAL-TIME SYSTEM PROMPT

Add real-time updates using Socket.io.

## FEATURES:

* Live stock price updates
* Live trades
* Leaderboard updates

## REQUIREMENTS:

* Backend emits events
* Frontend listens and updates UI

## EVENTS:

* stock_update
* trade_executed
* leaderboard_update

## OUTPUT:

* Socket server integration
* Frontend socket hooks
