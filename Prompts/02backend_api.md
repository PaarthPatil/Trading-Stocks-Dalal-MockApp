# ⚙️ BACKEND API PROMPT

Build a Node.js + Express backend for a stock simulation system.

## REQUIREMENTS:

* Use MVC structure
* Connect to PostgreSQL
* Import core logic module

## FEATURES:

### Auth

* Signup/Login (JWT)

### Stock APIs

* GET /stocks
* GET /stocks/:id

### Trading APIs

* POST /buy
* POST /sell

### Teams

* GET /teams
* GET /teams/:id

### Transactions

* GET /transactions

## RULES:

* Backend MUST call core logic for trading
* Validate all inputs
* Maintain transaction logs in DB

## OUTPUT:

* Full folder structure
* All routes, controllers, models
* Working server.js
